Agent 保存了一次成功的操作轨迹，不意味着下次一定会做得更好。它可能检索不到，也可能照搬已经失效的步骤，还可能把偶然成功归因于错误的原因。

《深入理解 AI Agent》第 8 章让我更关注“经验如何变成可复用能力”这条链路：记录只是起点，后面还需要评价、对照、归纳和验证。

## 先确认这次经验值得学习

假设一个助手填写表单，所有点击都成功了，最后也回复“提交完成”。如果必填字段实际为空，这条轨迹就不能当成成功示范。

即便结果正确，也要继续检查：是否靠了不允许的操作，是否存在未记录的人工补救，是否只对这个输入有效。用户没有投诉，也不等于结果已经通过验证。

因此，先保存事实，再生成判断。原始记录用于追溯，单次分析解释本次成败，跨案例归纳才形成候选经验。不要让一段自我反思直接成为全局规则。

## 根据经验的表达方式选择载体

| 载体 | 更适合沉淀什么 | 主要代价 |
|---|---|---|
| 知识库 | 事实、例外、适用条件与证据 | 检索遗漏、过期与错误应用 |
| Prompt 或 Skill | 可用语言说明的操作原则与流程 | 指令冲突、未触发或未遵循 |
| 程序与运行框架 | 确定性校验、重复操作、强制约束 | 实现维护、环境变化与错误固化 |
| 模型参数 | 风格、感知模式、工具使用与其他可训练能力 | 数据、训练、回归与回滚成本 |

这里的运行框架，也就是常说的 Harness，包括工具执行、状态管理、反馈与运行约束。四种载体可以组合，没有必要把所有问题统一塞进提示词或微调里。

## 知识回答“什么条件下成立”

“某接口在某版本需要某字段”，适合保存为有来源、有版本条件的知识。遇到其他版本，应重新查证，而不是直接照搬。

冲突证据不能只按成功次数投票。旧版成功十次、新版连续失败，可能表示适用条件变了；相同条件下时好时坏，可能表示结论不稳定。两者需要不同处理。

对一条经验是否可信，也没有通用的“两次成功即可”门槛。证据量、任务风险、环境差异和失败代价都应参与判断。

## Skill 回答“遇到这类任务如何行动”

能明确表达的经验，可以形成有作用域的操作说明。例如，处理长表格时先确认列定义，再检查缺失值，最后计算汇总；这比“以后仔细一点”更可执行。

一份可用说明需要交代触发场景、所需输入、关键步骤、验证方式与失败出口。已有同类说明时，优先修正对应部分，避免不断添加互相重叠的规则。

“Skill”并没有在所有系统中统一的含义。有的系统用它表示说明文件及配套资源，有的系统把可执行技能也称为 skill。应看清实际承载形式，不能只看名称。

## 程序让明确步骤稳定执行

如果某个检查规则清楚、重复出现、能够确定性验证，就适合交给代码。例如，发布前检查 frontmatter、限制允许提交的文件、查询部署状态，都不必每次让模型重新推理操作方法。

但把轨迹变成脚本，不能只是录制点击顺序。需要抽出变量，定义前提，检查中间状态，并验证最终结果。页面改版或接口返回发生变化时，应明确失败，避免继续执行错误流程。

[Voyager 的研究实现](https://voyager.minedojo.org/)展示了一种程序技能库：把技能保存为可执行代码，并在后续任务中检索和组合。它说明经验不必只保存成自然语言；具体效果仍取决于任务、环境与验证机制。

## 参数更新需要独立的数据与评估流程

有些能力难以靠几条规则完整表达，可以考虑通过监督微调、偏好优化或强化学习等方法训练。参数也能够学习事实和格式，不能把它的能力边界绝对化。

工程上的问题是：相比外部知识或程序，这种更新方式是否更合适。频繁变化、需要逐条追溯和删除的事实，通常更便于放在外部存储；稳定行为模式在数据充足、收益明确时，才更值得评估训练投入。

生产轨迹不能直接等同于训练数据。至少要处理隐私、错误示范、重复样本和分布偏差，并保留不参与训练或调参的评估任务。

## 学习闭环要允许失败与回滚

一个便于审计的流程可以是：

```text
执行任务并记录证据
    → 评价结果与过程
    → 归纳带适用条件的候选经验
    → 选择载体并生成候选版本
    → 新任务验证、旧任务回归
    → 发布；出现退化则撤回
```

评估不只看修改后总分有没有增加，还要区分：候选经验本身是否正确，任务中是否被加载，加载后是否被遵循，以及是否改善了未见过的任务。

例如，一份正确的 Skill 从未被触发，就不能只归因于“经验无效”；触发后严格遵循却频繁失败，则要重新检查流程本身。

还应把正式能力与候选能力隔离。负责改进系统的 Agent 不应该同时拥有随意降低验收门槛、删除失败记录和修改发布限制的权力，否则“进步”可能只是评分方式被改了。

这套思路的目标，是让经验逐步变成有证据、能复用、可撤销的能力。记录得更多、总结得更长，都不能单独证明发生了有效学习。
