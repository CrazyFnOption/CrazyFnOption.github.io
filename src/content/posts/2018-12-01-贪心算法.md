## 贪心算法

### 定义

贪心算法的本质目的也就在于对于一个问题来看，我可以用最简单的办法算出局部的解集，并且按照这个最简单的办法同样可以算出该问题的最终解决办法，即贪心算法。

#include<iostream>  
#include<algorithm>  
  
using namespace std;  
  
const int maxn = 100+5;  
  
struct Show{  
    int beg;  
    int en;  
}show[maxn];  
  
int main()  
{  
    int n;  
    while (cin>>n&&n!=0){  
        for (int i=0;i!=n;i++){  
            cin>>show[i].beg>>show[i].en;  
        }  
        stable_sort(show,show+n,  
        [](const Show &a, const Show &b){return a.en<b.en;});  
        int cnt=1;  
        for (int i=1,j=0;i<n;i++){  
            if (show[i].beg>=show[j].en){  
                cnt++;  
                j=i;  
            }  
        }  
        cout<<cnt<<endl;  
    }  
}

此处的关键就是从第一个开始把结束时间最早的进行一个相对位置的排序，然后把第一个结束的与后面开始的时间进行挨个挨个的比较，最终得出的结果就是在这里。

int greedy(vector<int> x,int k)  
{  
　　int i,sum = 1,n=x.size();  
　　sort(x.begin(),x.end());  
　　int temp = x[0];		//区间的起始位置  
　　for(i=1;i < n; ++i)  
　　　　if(x[i] - temp > k)　　{sum++,temp=x[i]};  
　　return sum;  
}

分别计数，用一个最简单的思维做出一整道题目的思路。
