## 二分查找

实现在单调有序的集合中查找元素，每次江集合分为左右两个部分，并且通过判断集合在哪个部分从而调整集合的上下界，重复知道找到目标元素为止。

举一个简单的例子，我要在1到100里面查找62，先拿62根这个其最中间的一个数进行比较。然后在一步一步的缩小集合的上下界，最后再来一步一步往里面缩

**下面是C++STL里面二分查找的函数：**

> binary_search  返回bool值,是否存在  
> lower_bound    返回可插入的最小位置的迭代器                                                                  即返回第一个符合条件的元素位置  
> upper_bound    返回可插入的最大位置的迭代器  
>                即返回最后一个符合条件的元素位置

在二分查找里面最典型的题目就是二分逼近求方程式的根了。

#include<iostream>  
#include<cmath>  
#include<algorithm>  
#include<iomanip>  
  
using namespace std;  
  
const double pre =1e-4;  
double x,y;  
  
double f(double x){  
    return 8*pow(x,4)+7*pow(x,3)+2*pow(x,2)+3*x+6-y;  
}  
  
int main()  
{  
    int t;  
    cin>>t;  
    while (t--){  
        cin>>y;  
        double x1=0,x2=100;//先把上下界在这里确定好  
        double mid=(x1+x2)/2;  
        if (f(x1)*f(x2)>0) cout<<"No solution!"<<endl;  
        else {  
            while (x2-x1>=pre){//这里必须写的是上下界线是多少，  
            不能写的是用于判断mid的条件。  
                if (f(x1)*f(mid)<0){  
                    x2=mid;  
                    mid=(x1+x2)/2;  
                }  
                else {  
                    x1=mid;  
                    mid=(x1+x2)/2;  
                }  
            }  
            cout<<fixed<<setprecision(4)<<mid<<endl;  
        }  
    }  
}

上面就是我第二次出错的地方，判断二分循环逼近的的条件不应该看mid的取值，而是应该看得是区间上界减去区间下界的范围从而来限定。

当需要求某凸性或凹形函数的极值，通过函数本身表达式并不容易求解时，就可以用三分法不断逼近求解。

#include<iostream>  
#include<algorithm>  
  
using namespace std;  
  
const int maxn = 100005;  
int a[maxn],n,c;  
  
//此过程就是在判断奶牛之间的间隔为这个值合不合适  
bool cc(int d){  
    int t=a[0],cnt=1;  
    for (int i=1;i!=n;i++){  
        if (a[i]-t>=d){  
            cnt++;  
            t=a[i];  
            if (cnt>=c)  
            return true;  
        }  
    }  
    return false;  
}  
//此过程就是在收录每一个值，然后再分别进行判断  
int solve(){  
    int x=0,y=a[n-1]-a[0];  
    while (x<=y){  
        int mid=(x+y)/2;  
        if (cc(mid))    x=mid+1;  
        else    y=mid-1;  
    }  
    return x-1;  
}  
//不过这种最大值最小值的题目需要多花时间想想。  
  
int main()  
{  
    while (cin>>n>>c){  
        for (int i=0;i!=n;i++)  
            cin>>a[i];  
        sort(a,a+n);  
        cout<<solve()<<endl;  
    }  
}
